# Student Database — SQL Practice Project

A beginner-friendly SQL project demonstrating core database operations: table creation, data insertion, filtering, grouping, and aggregate functions using a simple student records dataset.

## 📁 Project Overview

This project creates a `student` table inside a `clg` database and runs a series of SQL queries to explore the data — from basic `SELECT` statements to `GROUP BY` aggregations with `MAX`, `AVG`, and `MIN`.

## 🔍 Queries Included

- View all records
- Get distinct cities
- Limit results
- Count total students
- Group students by city
- Aggregate stats (max, avg, min marks) per city, sorted
- Update a specific student's record by `rollno`

## 🚀 How to Run

1. Install MySQL (or use any compatible SQL engine).
2. Open a terminal or MySQL client and run:
   ```bash
   mysql -u root -p < student_db.sql
   ```
3. Or copy-paste the contents of [`student_db.sql`](./student_db.sql) into your SQL client (MySQL Workbench, phpMyAdmin, etc.) and execute step by step.
